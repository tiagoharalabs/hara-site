## Governance

This token map adapts the PARADOX V4 Medium visual direction to the public H.A.R.A. Labs site.

It does **not**:
- promote PARADOX V4;
- claim PARADOX qualitative acceptance;
- mutate PARADOX live;
- change H.A.R.A. Commander MCP/OAuth behavior;
- create a competing identity asset.

Front A / issue #13 remains the authority for the canonical flat/matte, non-mirrored capybara asset.

## Policy

- Blue owns structure, navigation, focus and operational hierarchy.
- Gold is reserved for brand emphasis and primary CTA hierarchy.
- Colored glow is disabled by default.
- Decorative radial gold backgrounds are removed.
- Hero layout has one responsive ownership model instead of layered legacy overrides.
- Public-site spacing remains more open than the PARADOX cockpit.
- Root/public CSS parity is mandatory.
