## Why this release exists

The Commander 0.3.40 Agent polled:

`POST /api/device/calls/next`

on every two-second main-loop iteration, even when completely idle.

That creates about 43,200 call-poll requests/day per authorized Agent, plus
heartbeat and lease traffic. Seven always-on lab canaries therefore consumed
more than 300k Worker requests/day before normal portal/MCP traffic.

The public Commander origin was observed returning Cloudflare Error 1027:

`This website has been temporarily rate limited`

This was generated by Cloudflare before the Worker and explains the observed
HTTP 429 failures in Commander MCP and public health readback.

## Agent 0.3.41 polling contract

Linux and Windows now share:

- heartbeat: 60 seconds
- hot poll: 2 seconds
- idle poll: 10 seconds
- startup hot window: 30 seconds
- post-call hot window: 120 seconds

Receiving work immediately extends the hot window.

Permanent gate:

`validate_agent_request_efficiency.py`

Budget asserted by the gate:

- one idle Agent: 10,086 requests/day
- seven idle Agents: 70,602 requests/day

This is an interim bridge. The architectural target remains Event V2/WebSocket
push so idle Agents do not poll for work.

## Command robustness

Remote full and Simple MCP now normalize expected operational states instead of
turning them into generic MCP errors.

Examples:

- DEVICE_OFFLINE -> UNAVAILABLE / retryable
- DEVICE_BUSY -> BUSY / retryable
- DEVICE_CALL_TIMEOUT -> TIMEOUT / retryable
- file/path missing -> NOT_FOUND
- missing process session -> NOT_FOUND + list-sessions recommendation
- destination exists -> CONFLICT
- ambiguous computer/edit match -> NEEDS_INPUT
- invalid filesystem target -> INVALID_TARGET
- binary content -> UNSUPPORTED_CONTENT
- bounded-size violation -> LIMIT_EXCEEDED

Security/policy denials remain real MCP errors and fail closed.

Windows filesystem aliases are mapped to the same public semantics as Linux.

## Schema/downstream parity

The Simple MCP and Linux local MCP now advertise bounds that match the actual
Worker/Agent contract, including file reads/writes, editing, directory listing,
search, process listing and managed-process I/O.

Long process requests above the one-shot limit are routed to managed process
sessions rather than failing input validation.

## Process result truthfulness

Linux process envelopes now propagate:

- the real exit code when terminal;
- null while the process has no terminal exit code.

Self-test proves:

unknown/timeout state to zero.

## PTY interaction semantics

A real interactive test showed that PTY input echo can arrive before the
program's response.

The MCP descriptions now explicitly tell clients that
`interact_with_process` / `hara.process.interact` may return only immediate
terminal echo and that `read_process_output` / `hara.process.output` is the
follow-up authority for subsequent program output.

The Agent self-test now covers the sequence:

`process.start -> process.interact -> process.output -> terminal exit`

Marker:

`COMMANDER_PROCESS_INTERACT_FOLLOWUP=PASS`
