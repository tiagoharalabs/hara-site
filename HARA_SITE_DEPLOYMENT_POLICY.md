# H.A.R.A. site deployment policy

```text
DOCUMENT_ID=HARA_SITE_DEPLOYMENT_POLICY_V1
GOVERNANCE_AUTHORITY=TORRE_CONTROLE_HARA_V10
LANE_ID=SITE_DEPLOYMENT
DESTINATION_REPOSITORY=tiagoharalabs/hara-site
DOWNSTREAM_TARGET=CLOUDFLARE
LIFECYCLE=PROPOSED
RUNTIME_AUTHORITY=0
```

## Scope

This policy governs public website source and deployment-related changes. It is separate from platform source publication and private evidence publication.

## Required request

```text
FRONT_ID
WORKSTREAM_ID
AUTHORIZATION_RECEIPT
BASE_SHA
TARGET_BRANCH
EXPECTED_REMOTE_PREDECESSOR_SHA
ALLOWED_PATHS
PUBLIC_BUNDLE_SHA256
MANIFEST_SHA256
DEPLOYMENT_POLICY
SOURCE_RECEIPT
```

## Required flow

```text
READ_ONLY_PREFLIGHT
→ EXACT_MAIN_AND_REMOTE_BINDING
→ NON_MAIN_BRANCH
→ ISOLATED_WORKSPACE
→ EXACT_ALLOWED_PATHS
→ PUBLIC_CONTENT_CHECK
→ SECRET_AND_PRIVATE_PATH_CHECK
→ STATIC_OR_BUILD_VALIDATION
→ CONTENT_COMMIT
→ FAST_FORWARD_PUSH
→ DRAFT_PR
→ REMOTE_HEAD_AND_FILE_READBACK
→ REVIEW_AND_INTEGRATION_DECISION
→ CLOUDFLARE_DEPLOYMENT
→ PUBLIC_URL_READBACK
→ DEPLOYMENT_RECEIPT
```

## Prohibitions

```text
DIRECT_MAIN_PUSH=0
```

```text
PUBLIC_HTML

PUBLIC_IMAGES_AND_FONTS_WITH_RIGHTS
PUBLIC_METADATA
PUBLIC_CLOUDFLARE_CONFIGURATION_WITHOUT_SECRETS

```

## Required result

```text
BASE_SHA
BRANCH
COMMIT_SHA
PR_NUMBER
PR_URL
PUBLISHED_FILE_SHA256S
REMOTE_READBACK
BUILD_OR_STATIC_VALIDATION
CLOUDFLARE_DEPLOYMENT_ID
PUBLIC_URL_READBACK
SITE_DEPLOYMENT_RECEIPT
```

A Git commit or push is not a complete deployment receipt. Cloudflare status and the public URL must be verified after an accepted integration.

This policy does not authorize a merge or deployment by itself.
