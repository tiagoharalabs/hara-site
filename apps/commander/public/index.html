NOVO DISPOSITIVO

Instalar e parear

Pronto para instalar

Em sua conta H.A.R.A., escolha o sistema, gere um código e execute o instalador no computador que deseja conectar. O pareamento usa um código temporário, sem informar tokens na linha de comando.

01
Escolha o sistemaLinux ou Windows. O instalador oficial é baixado por HTTPS e verifica a release assinada.
Sistema
Configurações avançadas · Direct
Transporte
Cloud: o Gateway comercial encaminha comandos; nenhuma chave da OpenAI Platform é necessária. O Direct usa OpenAI Secure MCP Tunnel privado, e a execução permanece local.
Padrão: Cloud com confirmação por ação e sem início automático no próximo boot. O Direct é opcional.
02
Gere o código no portalCopie e cole quando o instalador solicitar “Pairing token”. Uso único, válido por até 10 minutos.
Código temporário10 minutos
—
03
Instale no computadorCopie o comando para o Terminal Linux ou PowerShell Windows. A instalação baixa a release oficial assinada por HTTPS. Ver a distribuição assinada no GitHub ↗
(tmp=$(mktemp) && trap 'rm -f $tmp' EXIT && curl -fsS --proto '=https' --tlsv1.2 --location --max-redirs 0 https://commander.haralabs.com.br/install/linux.sh -o $tmp && HARA_COMMANDER_APPROVAL_MODE=ASK_EVERY_ACTION HARA_COMMANDER_TRANSPORT_MODE=OUTBOUND_RELAY HARA_COMMANDER_TUNNEL_AUTOSTART=OFF HARA_COMMANDER_URL=https://commander.haralabs.com.br bash $tmp)
Para conectar o ChatGPT depois do pareamento, abra Comandos e integrações → MCP remoto e autentique pelo HARA Identity.Modo Direct: após parear, abra Comandos e integrações → Direct para configurar e autorizar o túnel OpenAI por 6 horas. Requer credenciais próprias da OpenAI Platform. Quando aparecer Pairing token, cole o código do passo 02 e pressione Enter. Depois, abra Comandos e integrações para iniciar ou parar as próximas sessões.
$haraPrevUrl=$env:HARA_COMMANDER_URL; $haraPrevApproval=$env:HARA_COMMANDER_APPROVAL_MODE; $haraInstaller=Join-Path $env:TEMP ('hara-commander-install-'+[guid]::NewGuid().ToString('N')+'.ps1'); try { $env:HARA_COMMANDER_URL='https://commander.haralabs.com.br'; $env:HARA_COMMANDER_APPROVAL_MODE='ASK_EVERY_ACTION'; Invoke-WebRequest -Uri https://commander.haralabs.com.br/install/windows.ps1 -OutFile $haraInstaller -UseBasicParsing -MaximumRedirection 0 -ErrorAction Stop; & powershell.exe -NoLogo -NoProfile -ExecutionPolicy Bypass -File $haraInstaller; if ($LASTEXITCODE -ne 0) { throw ('HARA_COMMANDER_INSTALL_EXIT_'+$LASTEXITCODE) } } finally { Remove-Item -LiteralPath $haraInstaller -Force -ErrorAction SilentlyContinue; $env:HARA_COMMANDER_URL=$haraPrevUrl; $env:HARA_COMMANDER_APPROVAL_MODE=$haraPrevApproval }
O PowerShell solicitará Pairing token em campo protegido. Cole o código do passo 02. Para sessões futuras, use a aba Comandos e integrações.
ConcluídoDepois de parear, vá a Dispositivos e clique em Atualizar. O Agent só fica online enquanto estiver ligado; não inicia automaticamente após reiniciar.

PowerShell local · beta
IniciarConecta e abre a sessão no Windows.

Verificar statusConfere se a sessão local está ativa.

A versão Windows está em beta: operações sensíveis ainda exigem homologação. O Agent não inicia sozinho após o login.

O que este contador mede: execuções governadas do Commander atribuídas à conta/plano. Ele não representa requests HTTP da infraestrutura e não inclui heartbeat, polling do Agent, health checks, carregamento do portal ou outras requisições da Cloudflare. O Commander na nuvem mantém apenas o mínimo necessário para conta, plano, presença e operação da ponte MCP; diagnósticos técnicos e histórico detalhado permanecem no Agent local.
