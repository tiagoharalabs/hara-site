PRODUTO H.A.R.A. LABS

Uma conexão simples para a IA operar no seu computador sem expor acesso remoto.

01

Login sem compartilhar senha

Sua conta é autenticada pelo HARA Identity. O Commander não recebe nem armazena sua senha.

02

Uso controlado

Cada execução governada contabiliza o uso de forma consistente, sem cobrança duplicada por repetição técnica.

03

Comprovantes por execução

Cada operação concluída pode ser vinculada a um comprovante auditável do resultado retornado.

04

Sem acesso irrestrito

O Commander expõe somente funções autorizadas e governadas; não oferece shell arbitrário ao cliente de IA.

Pronto para instalar

Gere um código temporário, escolha o sistema e execute o instalador. A conexão do Agent é somente de saída.

01
Gere o código de pareamentoVálido por até 10 minutos e substituído quando um novo código é criado.
Código temporário10 minutos
—
02
Escolha o sistema operacionalO mesmo código funciona para Linux ou Windows.
03
Copie e execute o instaladorDepois cole o código quando o instalador solicitar “Pairing token”.
(tmp=$(mktemp) && trap 'rm -f $tmp' EXIT && curl -fsS --proto '=https' --tlsv1.2 --location --max-redirs 0 https://commander.haralabs.com.br/install/linux.sh -o $tmp && HARA_COMMANDER_URL=https://commander.haralabs.com.br bash $tmp)
Execute em um terminal Linux. Nenhuma porta do roteador precisa ser aberta.
$haraPrevUrl=$env:HARA_COMMANDER_URL; try { $env:HARA_COMMANDER_URL='https://commander.haralabs.com.br'; $haraBootstrap=irm https://commander.haralabs.com.br/install/windows.ps1 -MaximumRedirection 0 -ErrorAction Stop; if (-not $haraBootstrap) { throw 'HARA_COMMANDER_BOOTSTRAP_EMPTY' }; iex ([string]$haraBootstrap) } finally { $haraBootstrap=$null; $env:HARA_COMMANDER_URL=$haraPrevUrl }
Execute no PowerShell. O Agent permanece ativo no logon e usa somente conexão de saída.
04
Aguarde o dispositivo aparecer em DispositivosQuando o heartbeat chegar, ele ficará disponível para seleção.
