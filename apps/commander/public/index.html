COMPUTADORES

Seus computadores

Instale o Commander Agent e mantenha uma conexão segura de saída com sua conta.

LINUX

Instalar no Linux

Disponível

Primeiro gere um código temporário. Depois execute o instalador no computador que você quer conectar.

(tmp=$(mktemp) && trap 'rm -f $tmp' EXIT && curl -fsS --proto '=https' --tlsv1.2 --location --max-redirs 0 https://commander.haralabs.com.br/install/linux.sh -o $tmp && HARA_COMMANDER_URL=https://commander.haralabs.com.br bash $tmp)
3. Execute o comando e cole o código quando o instalador pedir “Pairing token”. A conexão é somente de saída; nenhuma porta do roteador precisa ser aberta.
WINDOWS

Instalar no Windows

Disponível

Primeiro gere um código temporário. Depois execute o instalador no PowerShell do computador que você quer conectar.

$haraPrevUrl=$env:HARA_COMMANDER_URL; try { $env:HARA_COMMANDER_URL='https://commander.haralabs.com.br'; $haraBootstrap=irm https://commander.haralabs.com.br/install/windows.ps1 -MaximumRedirection 0 -ErrorAction Stop; if (-not $haraBootstrap) { throw 'HARA_COMMANDER_BOOTSTRAP_EMPTY' }; iex ([string]$haraBootstrap) } finally { $haraBootstrap=$null; $env:HARA_COMMANDER_URL=$haraPrevUrl }
3. Execute o comando e cole o código quando o instalador pedir “Pairing token”. O Agent permanece ativo no logon e usa somente conexão de saída.
PAREAMENTO

Código temporário

10 minutos

Use este código somente no computador que você está instalando. Ele funciona uma única vez e expira automaticamente.
