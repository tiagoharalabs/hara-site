Uma conexão simples para a IA operar no seu computador sem expor acesso remoto.

01

Login sem compartilhar senha

Sua conta é autenticada pelo HARA Identity. O Commander não recebe nem armazena sua senha.

02

Uso controlado

Cada execução governada contabiliza o uso de forma consistente, sem cobrança duplicada por repetição técnica.

03

Comprovantes por execução

Cada operação concluída pode ser vinculada a um comprovante auditável do resultado retornado.

04

Sem acesso irrestrito

O Commander expõe somente funções autorizadas e governadas; não oferece shell arbitrário ao cliente de IA.

Pronto para instalar

Gere um código temporário e instale o Agent. No modo recomendado, o computador fica pronto em segundo plano assim que a instalação termina. A conexão é somente de saída.

02
Escolha a plataforma e a autorizaçãoO mesmo código funciona em Linux ou Windows. “Sempre permitir” é o modo recomendado para uso diário.
Sistema
Autorização
Recomendado: o Agent fica disponível em segundo plano e executa somente operações governadas autorizadas neste computador.
03
Instale e prontoCopie o comando, execute e cole o código quando o instalador solicitar “Pairing token”.
(tmp=$(mktemp) && trap 'rm -f $tmp' EXIT && curl -fsS --proto '=https' --tlsv1.2 --location --max-redirs 0 https://commander.haralabs.com.br/install/linux.sh -o $tmp && HARA_COMMANDER_APPROVAL_MODE=PERSISTENT_TRUSTED HARA_COMMANDER_URL=https://commander.haralabs.com.br bash $tmp)
No modo “Sempre permitir”, a instalação termina com o Agent pronto em segundo plano. Em “Pedir confirmação”, use hara-commander start quando quiser autorizar ações.
$haraPrevUrl=$env:HARA_COMMANDER_URL; $haraPrevApproval=$env:HARA_COMMANDER_APPROVAL_MODE; $haraInstaller=Join-Path $env:TEMP ('hara-commander-install-'+[guid]::NewGuid().ToString('N')+'.ps1'); try { $env:HARA_COMMANDER_URL='https://commander.haralabs.com.br'; $env:HARA_COMMANDER_APPROVAL_MODE='PERSISTENT_TRUSTED'; Invoke-WebRequest -Uri https://commander.haralabs.com.br/install/windows.ps1 -OutFile $haraInstaller -UseBasicParsing -MaximumRedirection 0 -ErrorAction Stop; & powershell.exe -NoLogo -NoProfile -ExecutionPolicy Bypass -File $haraInstaller; if ($LASTEXITCODE -ne 0) { throw ('HARA_COMMANDER_INSTALL_EXIT_'+$LASTEXITCODE) } } finally { Remove-Item -LiteralPath $haraInstaller -Force -ErrorAction SilentlyContinue; $env:HARA_COMMANDER_URL=$haraPrevUrl; $env:HARA_COMMANDER_APPROVAL_MODE=$haraPrevApproval }
No modo “Sempre permitir”, o Agent fica pronto em segundo plano após a instalação. Em “Pedir confirmação”, abra a sessão local quando quiser autorizar ações.
